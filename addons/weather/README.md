# Weather System (Lite)

Free 2D and 3D weather for Godot 4.5+. Six states, both drivers, a per-state look
profile, a weather readout, and a no-code setup dock.

Press F5 to walk through it. Keys 1 to 6 pick a weather.

## Install

1. Copy `addons/weather/` into your project.
2. Project Settings, Plugins, enable **Weather System (Lite)**.
3. Open the **Weather · Setup** dock, pick a weather, pick a scene, press Apply.
   Tick **Show the weather to the player** first for a small readout in the
   bottom-right corner.

## What the full version adds

This edition draws weather. The full version makes it behave like weather.

- Weighted transitions per climate, so the weather runs itself
- A forecast you can read and build quests on, saved with the game
- Save support for the weather, the strength and the whole forecast
- Event mirroring for Quests and Achievements
- Gameplay hooks: snow slows your player, fog hides them from enemies
- A one-click box in the dock that wires that up for you
